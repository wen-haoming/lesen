# Lesen

Chrome extension (114+, MV3) that aggregates feeds from Xueqiu, Weibo, and X into one reading UI—popup, reader window, or a narrow **side panel page** (`sidepanel.html`), not a native docked browser sidebar.

- **Install (updates):** [Chrome Web Store](https://chromewebstore.google.com/detail/lesen-%C2%B7-%E8%8E%B1%E6%A3%AE-%C2%B7-%E5%A4%9A%E6%BA%90%E4%BF%A1%E6%81%AF%E8%81%9A%E5%90%88/dakdgplahfkbblfpafdjeipneioajgdf)
- **Tagged downloads:** [GitHub Releases](https://github.com/wen-haoming/lesen/releases) (`lesen-v*.*.*` tags)
- **Build from source:** see [README.md](README.md) (Chinese, canonical for this repo)
- **Self-hosting auth/sync:** [SELF_HOSTING.md](SELF_HOSTING.md)
